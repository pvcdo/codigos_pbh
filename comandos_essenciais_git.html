Guia de Comandos Essenciais do Git

Este guia rápido cobre as configurações iniciais do Git e os comandos mais utilizados no dia a dia do desenvolvimento.

Configurações Iniciais

Antes de começar, é fundamental configurar seu nome e e-mail. Essas informações serão vinculadas a cada commit que você fizer.

# Configura seu nome de usuário globalmente
git config --global user.name "Seu Nome"
# Configura seu e-mail globalmente
git config --global user.email "seu-email@example.com"
# Verifica se as configurações foram salvas
git config --global --list

Criando e Gerenciando Repositórios

Os comandos abaixo ajudam a iniciar um novo repositório ou a copiar um existente.

  • git init: Cria um novo repositório Git vazio no diretório atual.
  • git clone [URL]: Clona um repositório remoto para sua máquina local.
  • git status: Exibe o status do seu repositório, mostrando arquivos modificados, novos ou prontos para commit.

Salvando Alterações (Commits)

O fluxo de trabalho básico do Git envolve adicionar arquivos à "área de stage" e depois salvá-los com um commit.

  • git add .: Adiciona todas as alterações do diretório atual para a área de stage.
  • git add [nome-do-arquivo]: Adiciona um arquivo específico para a área de stage.
  • git commit -m "Mensagem do commit": Salva as alterações da área de stage. A mensagem deve ser curta e descritiva.
  • git log: Exibe o histórico de commits do seu repositório.

Sincronizando com Repositórios Remotos

Use estes comandos para manter seu código local e remoto atualizados.

  • git remote add origin [URL]: Associa um repositório local a um repositório remoto (geralmente chamado de origin).
  • git push -u origin [nome-do-branch]: Envia seus commits locais para o repositório remoto. O -u (upstream) só precisa ser usado na primeira vez.
  • git pull: Baixa e mescla as alterações do repositório remoto para o seu local.

Ramificações (Branches)

Branches permitem que você trabalhe em novas funcionalidades sem afetar o código principal (main ou master).

  • git branch: Lista todas as branches locais.
  • git branch [nome-da-branch]: Cria uma nova branch.
  • git checkout [nome-da-branch]: Muda para a branch especificada.
  • git checkout -b [nome-da-branch]: Cria e já muda para a nova branch (atalho).
  • git merge [nome-da-branch]: Mescla as alterações de uma branch para a branch atual.
