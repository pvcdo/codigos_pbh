Guia Completo: Criando .gitignore via Linha de Comando

Este guia consolida todas as instruções para criar funções e scripts de linha de comando para gerar arquivos .gitignore de forma rápida e eficiente em diferentes sistemas operacionais.

Índice

  • 1. Windows: Script Fixo para Clasp (Versão Corrigida)
  • 2. Windows: Script Genérico com Argumentos
  • 3. Solução de Problemas: Script Imprimindo no Terminal
  • 4. Linux e macOS: Função Bash
  • 5. Alternativa Moderna: Função Nativa do PowerShell

1. Windows: Script Fixo para Clasp (Versão Corrigida)

Este script cria um arquivo .gitignore com conteúdo pré-definido. Esta é a versão corrigida e robusta que funciona tanto no Prompt de Comando (CMD) quanto no PowerShell.

Crie um arquivo chamado criar_gitignore_clasp.bat:

@echo off

:: Cria/sobrescreve o .gitignore com a primeira linha de texto
echo # Arquivo de configuração do Clasp com credenciais > .gitignore

:: Anexa as linhas seguintes ao arquivo já criado
echo .clasp.json >> .gitignore
echo appsscript.json >> .gitignore
echo. >> .gitignore
echo # Pasta de módulos do Node.js (se aplicável) >> .gitignore
echo node_modules/ >> .gitignore

echo Arquivo .gitignore criado com sucesso na pasta atual.

Para usar, navegue até a pasta do seu projeto pelo terminal e execute o comando: criar_gitignore_clasp.bat

2. Windows: Script Genérico com Argumentos

Para tornar a ferramenta mais flexível, este script aceita os nomes dos arquivos e pastas a serem ignorados como argumentos na linha de comando.

Crie um arquivo chamado criar_gitignore.bat:

                
                    @echo off
                    setlocal

                    :: Verifica se algum argumento foi passado. Se não, exibe a ajuda e sai.
                    if "%1"=="" (
                        echo.
                        echo Uso: %0 [arquivo1] [pasta2/] [padrao3*] ...
                        echo.
                        echo Exemplo: %0 node_modules/ .env *.log
                        echo Este comando cria um arquivo .gitignore com as entradas fornecidas.
                        echo.
                        goto :eof
                    )

                    :: Cria o arquivo .gitignore (sobrescrevendo se já existir) com um cabeçalho.
                    echo # Arquivos e pastas a serem ignorados pelo Git > .gitignore
                    echo. >> .gitignore

                    :: Itera sobre todos os argumentos passados para o script e os adiciona ao .gitignore.
                    echo # Entradas adicionadas via linha de comando: >> .gitignore
                    for %%G in (%*) do (
                        echo %%G >> .gitignore
                    )

                    echo.
                    echo Arquivo .gitignore criado/atualizado com sucesso!
                    echo.

                    endlocal

Como Utilizar

Execute no terminal, passando os arquivos/pastas como argumentos:

                
                    criar_gitignore.bat node_modules/ .env *.log build/ dist/

3. Solução de Problemas: Script Imprimindo no Terminal

O Problema

A versão inicial do script para Windows pode ter falhado se executada no PowerShell. Em vez de criar um arquivo, o conteúdo era apenas impresso na tela do terminal.

A Causa

Isso ocorre porque o PowerShell pode interpretar blocos de comando entre parênteses ( ... ) de forma diferente do CMD, fazendo com que o redirecionamento de saída > não funcione como esperado para o bloco inteiro. A solução, implementada na Seção 1, é redirecionar cada linha individualmente, usando > para a primeira e >> (anexar) para as subsequentes.

No windows temos que colocar este bat no path, seja editando as variáveis de ambiente, seja salvando no system32

4. Linux e macOS: Função Bash

Para ambientes baseados em Unix, você pode adicionar uma função ao seu arquivo de configuração do shell (~/.bashrc ou ~/.zshrc).

                
                    function criar_gitignore_clasp() {
                        echo "# Arquivo de configuração do Clasp com credenciais" > .gitignore
                        echo ".clasp.json" >> .gitignore
                        echo "appsscript.json" >> .gitignore
                        echo "" >> .gitignore
                        echo "# Pasta de módulos do Node.js (se aplicável)" >> .gitignore
                        echo "node_modules/" >> .gitignore
                        echo "Arquivo .gitignore criado com sucesso!"
                    }

Após adicionar, recarregue seu terminal ou execute source ~/.bashrc. Depois, use o comando criar_gitignore_clasp em qualquer pasta.

5. Alternativa Moderna: Função Nativa do PowerShell

Para usuários que preferem o PowerShell no Windows, criar uma função nativa é a abordagem mais elegante e robusta.

  1. Abra seu perfil do PowerShell com o comando: notepad $PROFILE
  2. Adicione o código abaixo ao arquivo e salve: 
                                
                                function New-ClaspGitIgnore {
                                    $content = @"
                                # Arquivo de configuração do Clasp com credenciais
                                .clasp.json
                                appsscript.json

                                # Pasta de módulos do Node.js (se aplicável)
                                node_modules/
                                "@
                                    Set-Content -Path ".gitignore" -Value $content
                                    Write-Host "Arquivo .gitignore criado com sucesso!"
                                }
  3. Recarregue seu perfil fechando e abrindo o PowerShell ou executando o comando: . $PROFILE

Feito isso, você pode executar o comando New-ClaspGitIgnore em qualquer diretório para gerar o arquivo.
