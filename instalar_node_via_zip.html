Instalando o Node.js no Windows a partir do Binário Autônomo (.zip)

Esta guia passo a passo explica como instalar o Node.js no Windows usando o arquivo binário autônomo (.zip). Este método é ideal quando você não possui permissões de administrador ou prefere ter várias versões do Node.js instaladas em seu sistema.

Passo 1: Baixar os Arquivos Binários

Para começar, baixe o pacote binário autônomo diretamente do site oficial do Node.js.

  1. Acesse a página de download do Node.js: https://nodejs.org/en/download/
  2. Na seção **Other downloads**, localize a sua arquitetura de sistema (geralmente 64-bit) e baixe o arquivo Windows Binary (.zip).

Passo 2: Extrair e Organizar os Arquivos

Depois de baixar o arquivo, extraia-o para um local de fácil acesso e onde você deseja manter a sua instalação do Node.js.

  1. Crie uma pasta em um local de sua preferência, por exemplo, C:\dev\nodejs.
  2. Extraia o conteúdo do arquivo .zip para essa nova pasta.

A pasta extraída conterá os executáveis node.exe e npm, além de outros arquivos necessários.

Passo 3: Configurar os Diretórios para Módulos Globais e Cache

Para evitar problemas de permissão e manter seus módulos globais organizados, é recomendado criar pastas dedicadas para o npm. O npm é o gerenciador de pacotes do Node.js.

  1. Dentro da pasta onde você extraiu o Node.js (por exemplo, C:\dev\nodejs\node-v20.12.2-win-x64), crie duas novas pastas:
    • npm-global (para os módulos instalados globalmente com npm install -g)
    • npm-cache (para o cache do npm)
  2. Em seguida, abra o **Prompt de Comando** (cmd) ou **PowerShell** e use os seguintes comandos para configurar o npm, substituindo o caminho pelo seu:
    3. npm config set prefix "C:\dev\nodejs\node-v20.12.2-win-x64\npm-global"
npm config set cache "C:\dev\nodejs\node-v20.12.2-win-x64\npm-cache"

Passo 4: Adicionar os Caminhos ao PATH do Sistema

Para que você possa usar os comandos node e npm de qualquer lugar no seu terminal, é necessário adicionar os caminhos das pastas do Node.js e dos módulos globais à variável de ambiente **PATH** do seu sistema.

  1. Abra o menu Iniciar e digite "Variáveis de Ambiente", depois clique em "Editar as variáveis de ambiente do sistema".
  2. Na janela que se abrir, clique no botão "Variáveis de Ambiente...".
  3. Na seção **"Variáveis de usuário"**, encontre a variável chamada Path e clique em **"Editar"**.
  4. Clique em **"Novo"** e adicione o caminho completo para a pasta onde você extraiu o Node.js. Por exemplo: C:\dev\nodejs\node-v20.12.2-win-x64.
  5. Clique em **"Novo"** novamente e adicione o caminho para a pasta **npm-global** que você criou. Por exemplo: C:\dev\nodejs\node-v20.12.2-win-x64\npm-global.
  6. Clique em **"OK"** para fechar todas as janelas.

Passo 5: Verificar a Instalação

Para confirmar se tudo foi configurado corretamente, abra um **novo** Prompt de Comando (ou PowerShell) e execute os seguintes comandos:

node -v
npm -v

Se a instalação foi bem-sucedida, os comandos retornarão as versões do Node.js e do npm.

Para testar se os módulos globais funcionam, instale um e verifique sua versão:

npm install -g nodemon
nodemon -v

Isso deve retornar a versão do Nodemon, indicando que a instalação global está funcionando corretamente.
